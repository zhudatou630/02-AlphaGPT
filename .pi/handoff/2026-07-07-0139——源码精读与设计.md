## 关键决策及理由

| 决策 | 理由 |
|---|---|
| **打分器 = top分位×视界N（纯信号质量，无摩擦）** | rank IC 幅度盲（甲8个+2%/乙2个+50% 分不出）；全实盘模拟把摩擦焊进基础模块；top分位×视界N 幅度敏感(解决甲乙)、时段匹配(N=波段天数)、无摩擦 |
| **波段性用"视界N"吸收，不用退出规则焊进打分器** | "持有多久"是预测视界(属信号性质)进打分器；"止损/止盈/移动止盈"是执行机制(属摩擦)进验证层。曾一度想把退出规则塞打分器，第一性审视后判为执行渗漏，已修正 |
| **摩擦全部下沉验证层** | 打分器共享策略不共享摩擦；真实度逐层递增，训练层不必跟实盘一样真实 |
| **验证层结构必需（非可选）** | 优化器不能自改目标；AlphaGPT 缺这层→训练直跳实盘；我们必须建 |
| **固定 ETF 池起步，时序 token，横截面 token 可选** | 小固定池+宽基高相关→横截面分化小；top-K 执行已做横截面选择；横截面 token 留到大池/动态池才必需 |
| **保留解耦（公式即 artifact）+ 三层分离 + 多退出防线** | 对标主流量化分层（alpha→风险→执行），单一职责 |
| **接上 critic + 多 seed** | AlphaGPT 定义了 critic 却没用→方差偏高；多 seed 看稳健，单 seed 暴利不可信 |
| **T+1 收益对齐：signal[t]→open[t+1]起算 N 天收益** | T+1 下最早 t+1 开盘买、t+2 开盘才能卖；用同日收益=前视偏差 |
| **数据源 akshare 免 token** | 零门槛，ETF 日线干净；不依赖 Tushare token / Birdeye 付费 |

## 接手者必须知道的上下文

### 核心术语（文档里高频，需对齐含义）
- **三件套**：Transformer（写公式的脑子）+ StackVM（算公式的栈式计算器）+ REINFORCE（打分纠错的老师）
- **token 词表**：特征 token + 算子 token，是公式搜索空间的天花板
- **打分器（scorer）**：训练目标函数，给定公式+数据输出一个分数；我们定稿为 `top分位×视界N`
- **甲/乙错配**：原项目训练挑中"广而平庸"的甲、淘汰"少而爆赚"的乙，但实盘乙远胜——训练/实战目标反着的经典例子
- **策略 vs 摩擦**：策略=选股规则+持有视界（打分器与实盘共享）；摩擦=成本/退出规则/T+1（只进验证层）
- **真实度逐层递增**：打分器→验证→纸面→实盘，每层加一层真实度
- **公式即 artifact**：训练产出可读公式序列化文件，下游零耦合消费
- **universe mask**：`[N, T]` 布尔掩码，标记每个品种每天是否在池子里（动态池用）
- **横截面 token**：在 t 时刻跨 N 品种比较的算子（CS_RANK/CS_ZSCORE 等），固定池可选、大池/动态池必需
- **视界 N**：信号评估的目标持有天数（=波段天数），吸收波段性
- **rank IC**：信号排名与收益排名的相关性；幅度盲，我们不用它当打分器
- **moonbag / 蜜罐检测**：原项目 Meme 币特有概念（半仓止盈 / 进场前试卖价验退出），我们 A 股不用但原理可鉴

### 硬约束（A 股特性，与原项目 Meme 币根本不同）
- **T+1**：当天买次日才能卖；退出信号当天产生、次日开盘执行；不能日内止损；打分器收益必须从 t+1 开盘起算
- **日频**（非 1 分钟）
- **低费率**：万几手续费，滑点极低（但高频换手仍累积）
- **涨跌停 / 停牌**（非流动性枯竭/蜜罐）
- **个人用户、波段交易**（非机构、非剥头皮）——持仓粘性、不每日轮动

### 数据源
- **akshare**（免 token）：拉 A 股 ETF 日线，须用**前复权 qfq** 保证价格连续
- 不用 Tushare（要 token）/ Birdeye（Meme 币付费）/ PostgreSQL+TimescaleDB（原项目重栈，我们 20 只×10 年≈5 万行，pandas/parquet 足够）

### 重要原则（落地时不可违背）
1. **打分器只放纯信号质量（top分位×视界N），摩擦全下沉验证层**——别把退出规则/成本/T+1 焊进打分器
2. **T+1 收益对齐**：signal[t] → 从 open[t+1] 起算的 N 天收益，否则前视偏差
3. **验证层不可省**——它是结构必需的安全网（优化器不能自改目标）
4. **先固定公式跑通数据+打分器+验证，再开 Transformer**——两件新事不同时压
5. **多 seed 看稳健**，单 seed 暴利不可信
6. **宽基 ETF 分化小是最大风险**——验证层揭示，对策是换池子不是改打分器
