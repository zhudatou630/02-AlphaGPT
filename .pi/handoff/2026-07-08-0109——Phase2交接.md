## 关键决策及理由

| 决策 | 选定项 | 理由 |
|---|---|---|
| Phase 2 定位 | 框架正确优先，策略有效只做观察项 | 固定公式只是测试探针，不能用其收益判断系统成败 |
| 固定公式用途 | 只用于 Phase 2 测试，不参与训练、不限制 Phase 3 搜索空间 | 降低排错维度，先验证 scorer / validator 链路 |
| scorer 分层 | 纯信号质量，不含手续费、滑点、止损、持仓、换手惩罚 | scorer 未来是训练 reward，应简单、稳定、可解释 |
| scorer 收益对齐 | `t` 日信号，`open[t+1] -> open[t+1+N]` | 避免前视偏差，符合日频收盘决策、次日开盘执行 |
| scorer top 规则 | available universe 内 top 20%，`2 <= top_k <= 4` | 保留分位思想，同时适配当前 17 只小 ETF 池 |
| 样本起点 | `available_count >= 10`，即 `2016-11-04` | 早期横截面过窄，2016 后样本仍足够 |
| validator 成交假设 | 收盘决策、次日开盘统一成交 | 当前只有日频 OHLCV，不假装知道盘中路径 |
| validator 仓位 | 3 个固定仓位槽，只做多、无杠杆、允许现金 | 避免无限子弹，保持简化可审计 |
| 买入资格 | `signal > 0` 且排名 top 3 | 避免所有 ETF 信号都差时强行满仓 |
| 持有资格 | `signal > 0` 且排名 top 5 | 买入严格、卖出有粘性，降低排名噪声换手 |
| Phase 2A 退出 | 信号失效、-5% 止损、最长持有 N 日 | 第一版保留基本风控和时间边界 |
| 会话后续认识 | validator 中 N 强制卖出可能截断右尾 | 无 N 上限临时探索显示趋势单收益更完整，N 更适合留在 scorer 作为训练视界 |
| 固定公式 | `mom_10`、`ma_gap_5_20`、`volume_confirmed_mom_10`、`reversal_5` | 覆盖趋势、平滑趋势、量价确认、反向探针 |
| 输出物 | CSV 审计产物，不先做图 | Phase 2 重点是可排查明细 |
| benchmark | available universe 等权持有 | 内部参照，不引入额外数据源口径 |

### 术语与约束

- 三件套：Transformer 生成公式、VM/StackVM 执行公式、REINFORCE 用 scorer 训练生成器。
- scorer：训练目标函数；当前为 top 分位 × 视界 N 的纯信号质量，不含摩擦。
- validator：外部验证层；不参与训练，用于检查真实交易约束下的净值、回撤、交易和持仓状态。
- fixed formula / 固定公式：Phase 2 测试探针，不参与 Phase 3 公式搜索。
- available universe：每天只在当日可交易 ETF 中排序和选 top。
- universe mask：`[N,T]` 布尔矩阵，标记每只 ETF 每天是否可用。
- bfq：不复权原始行情。
- qfq_latest：当前前复权派生价格，不是严格 point-in-time 复权。
- T+1 对齐：`t` 日信号，最早 `open[t+1]` 买入；scorer 用 `open[t+1] -> open[t+1+N]` 评价。
- A 股 ETF，日频，个人波段交易，非剥头皮。
- 不静默混源。TDX 出问题先报告用户，不自动切 Tushare 或 akshare。
- Phase 3 前仍不要碰实盘接口；验证层未过，不进入真钱。
