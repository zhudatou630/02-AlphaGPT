## 卡点 / 未决决策

1. **绝对价格终端是否保留**  
   V2 目前允许 `open/high/low/close` 直接作为公式终端。绝对价格可能携带名义价格尺度，以及 latest event-adjustment 对历史价格水平的缩放。收益率和价格比值不受普通事件前历史缩放影响。是否进一步改成收益率、`OHLC/previous_close` 或因果归一化终端，尚未决定。相关边界记录在 `docs/V2_价格因子主线.md`。

2. **V2 baseline 尚未实现**  
   旧 `scripts/phase2_run_fixed_formulas.py`、`scripts/phase2b_run_fixed_formulas.py` 和 `scripts/phase3a_random_formulas.py` 属于 V1，不能直接作为 V2 正式入口。需要新增 V2 固定价格公式 sanity 和同预算随机 baseline。

3. **Phase1b 从新机器重建依赖本地 Tushare flow**  
   `scripts/phase1b_build_event_adjusted_data.py` 默认读取 `data/processed/data_quality/tushare_probe/tushare_fund_daily_probe.parquet`。该文件未提交，因为包含付费数据。当前仓库已提交 V2 OHLC panel，可直接训练；若要从源头重建，需要先在本地准备 Tushare 探针数据。

4. **AutoDL 当前已关机**  
   后续 GPU smoke 或正式训练前，需要用户重新开启实例。登录信息只保存在 `.pi/local/autodl-login.md`，不得提交或复述。

5. **尚未创建 V2 正式 tag**  
   当前 V2 是已推送主线，但尚未完成 baseline/GPU 重跑，因此没有打正式 V2 研究结果 tag。

## 关键决策及理由

1. **冻结 V1，不整体复制工程**  
   V1 数据和产物受污染，但 VM、scorer、validator 和训练框架仍可复用。整体 archive 后复制代码会形成双份核心实现，长期容易漂移。

2. **V1 和 V2 使用独立 vocab version**  
   直接从 V1 删除 `volume/amount` 会改变后续 token ID。V1 保持 `phase3a-v1`，V2 使用 `price-event-v2`，旧整数 token 不得直接迁移。

3. **旧 checkpoint 不续训**  
   数据和搜索空间都改变，旧模型参数已经吸收脏奖励。V2 必须从随机初始化开始。

4. **V2 不暴露 volume/amount，但数据治理层保留 flow**  
   ETF 场内流动性存在长期结构变化，当前阶段不宜把原始 flow 当 alpha。flow 仍用于数据质量、停牌和 tradable mask。

5. **TDX 与 Tushare 分工**  
   TDX raw OHLC 和完整事件用于价格复权；本地 Tushare `fund_daily` 用于修正少量 TDX volume/amount 异常和生成 tradable mask。V2 训练 panel 只包含价格。

6. **ResearchSpec 和内容哈希是运行时门禁**  
   Git tag 只能追溯代码，不能阻止旧 checkpoint、新数据和新词表混用。V2 在 artifact/checkpoint 层强制校验研究身份。

7. **不提交付费 flow 和本地分析产物**  
   Git 只提交代码、测试、文档、冻结清单和价格-only V2 panel；Tushare flow、Phase1b 完整数据、旧污染分析和 V2 runs 保留本地。
