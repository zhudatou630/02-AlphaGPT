**关键决策**：
- Phase3 环境顺序 → 先做 Phase3-0：安装并验证 PyTorch，再写 Phase3 训练相关代码（备选：先写 numpy VM、不装 torch；先写 PyTorch 代码最后再装）— 理由：Phase3 最终目标包含 Transformer/REINFORCE，`torch` 环境风险应前置暴露。
- Python 环境位置 → 使用项目内 `.venv`（备选：直接装到当前 Python；使用 conda/mamba；只写安装说明不实际安装）— 理由：隔离 PyTorch 及训练依赖，不污染全局环境，后续迁移或复现实验更清楚。
- git 约束 → 创建 `.venv` 前先把 `.venv/` 加入 `.gitignore`（备选：只靠手动不 add；写入 `.git/info/exclude`）— 理由：虚拟环境和 PyTorch 文件体积大，不能进入版本控制；项目规则应固化在仓库忽略文件中。
- PyTorch 版本形态 → 安装 CPU 版 PyTorch，不装 CUDA 版（备选：CUDA/GPU 版；先检测 GPU 再决定）— 理由：本机没有 NVIDIA GPU；Phase3 起步目标是小规模闭环，CPU 版复杂度更低且足够验证。
- 算力路线 → 本机小规模训练优先，暂不租 GPU 服务器（备选：一开始按 GPU 服务器设计）— 理由：当前数据规模为 17 只 ETF、4007 个交易日，Phase3 首要目标是训练闭环，不是大规模搜索。
