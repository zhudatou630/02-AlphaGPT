# Phase2方案

**时间**：2026-07-07 04:24
**背景**：Phase 1 数据地基已跑通，Phase 2 需要先用固定公式验证 scorer / validator 框架，而不是直接进入 Transformer 公式搜索。

**关键决策**：
- Phase 2 定位 → 框架正确优先，策略有效只做观察项（备选：策略有效优先、两者并重）— 理由：固定公式只是测试探针，过早用收益判断系统成败会混淆数据、scorer、validator、公式强弱和 ETF 池分化问题。
- 固定公式用途 → 只作为 Phase 2 测试探针，不参与训练、不限制 Phase 3 搜索空间（备选：用固定公式做策略筛选）— 理由：先验证数据到 signal、scorer、validator 的链路，Phase 3 再替换为 Transformer 生成公式。
- scorer 分层 → 纯信号质量，不含手续费、滑点、止损、持仓、换手惩罚（备选：加入轻换手惩罚、完整回测分数）— 理由：scorer 未来是训练 reward，应保持简单稳定；现实约束交给 validator 审计。
- scorer 收益对齐 → `t` 日信号，`open[t+1] -> open[t+1+N]` 毛收益（备选：同日收益、收盘到收盘）— 理由：避免前视偏差，并符合收盘决策、次日开盘成交的日频假设。
- 视界 N → `N=10` 主视界，`N=5` 对照视界；scorer 中为预测视界，validator 中为最长持有期（备选：只跑一个 N、多 N 网格搜索）— 理由：匹配短波段意图，同时避免 Phase 2 变成参数寻优。
- scorer top 规则 → available universe 内 top 20%，`top_k = ceil(count * 20%)`，限制 `2 <= top_k <= 4`（备选：固定 top 3、纯 top 20%）— 理由：保留分位思想且适配当前 17 只小池，避免早期样本只选 1 只。
- 样本起点 → 从 available ETF 数量 `>=10` 的第一天开始，即 2016-11-04（备选：2010 全样本、2020-12-18 全员可用后）— 理由：早期横截面太窄；2016-11-04 后仍有足够样本。
- validator 角色 → 不参与训练，只做现实检验；Phase 2 暂不考虑手续费和滑点（备选：作为 scorer 含摩擦镜像、加入交易成本）— 理由：validator 解耦于训练，可更接近简化实盘；成本滑点先搁置，避免第一版过重。
- validator 成交假设 → 收盘决策、次日开盘统一成交（备选：盘中触发成交）— 理由：当前只有日频 OHLCV，不能假装知道盘中路径；该假设可复现且避免前视。
- validator 仓位模型 → 有限资金账户，3 个固定仓位槽，每槽 1/3，只做多、无杠杆；剩余仓位留现金（备选：满仓等权、信号强度加权）— 理由：避免无限子弹；不让 signal 尺度污染仓位。
- 空槽补位 → 退出只释放自己的槽位，剩余持仓不自动放大；释放槽位可用最新信号补位，无候选则留现金（备选：等待固定调仓日、平分给剩余持仓）— 理由：保持固定风险槽位，并允许轮动系统持续寻找新机会。
- 买入资格 → signal > 0 且排名 top 3，允许空仓（备选：始终满仓 top 3、外部大盘过滤）— 理由：避免整体信号差时强行满仓。
- 持有资格 → signal > 0 且排名 top 5（备选：持有也 top 3、只要求 signal > 0）— 理由：买入严格、卖出有粘性，降低排名噪声导致的换手。
- 退出规则 → 信号失效、收盘价相对买入价亏损 <= -5%、持有满 N 日；暂不做止盈（备选：加入固定止盈、移动止盈、只做固定 N）— 理由：保留基本风控和时间边界，同时避免第一版止盈参数化。
- 固定公式 → `mom_10`、`ma_gap_5_20`、`volume_confirmed_mom_10`、`reversal_5`，不做窗口参数搜索（备选：2 条公式、10-20 条网格）— 理由：覆盖趋势、平滑趋势、量价确认、反向探针，足够验收框架。
- 输出物 → CSV 审计产物：`formula_summary.csv`、`scorer_daily.csv`、`validator_daily.csv`、`trades.csv`；第一版不画图（备选：只输出 summary、直接做图表报告）— 理由：Phase 2 需要可排查的明细，图表可后置。
- benchmark → available universe 等权持有，不引入外部指数或额外数据源（备选：不做 benchmark、多 benchmark、510300）— 理由：给信号轮动提供内部参照，同时避免混入新数据口径。

**待定/未决**：
- 手续费、滑点、冲击成本暂不进入 Phase 2 第一版；等 validator 状态机跑通后再加。
- 止盈、移动止盈、日内触发暂缓；当前日频数据不足以支撑盘中路径假设。
