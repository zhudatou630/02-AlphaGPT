# formal 训练方案

**时间**：2026-07-13 06:28
**背景**：Stage D formal 训练上 GPU 前的对齐——研究定位、训练参数、执行策略、监工授权。

## 关键决策

- **研究定位** → formal 产出"Transformer vs 随机的搜索层比较结论 + 一批 top-50 公式库"，不指望直接出交易策略，不打开 2022/2023 样本外（备选：指望跑完出可交易策略）— 理由：搜索层和策略层分离；formal 只回答搜索层问题，策略验证留给后续 validator。

- **胜负门槛** → 接受"3 对赢 2"的倾向性结论（备选：加 seed 到 5 对求统计铁证）— 理由：个人探索，初步判断够；加 seed 成本翻倍但结论硬度提升有限。

- **训练参数** → batch 8192 / lr 1e-3 / entropy 0.005（备选：原配置 batch 256 / lr 1e-4 / entropy 0.001）— 理由：原配置 pilot 显示探索不足、best 早见顶；向 AlphaGPT 靠拢，大 batch 降梯度方差、大 lr 加速、entropy 缓解局部收敛。

- **训练预算** → 800 万 attempts/run（备选：100 万）— 理由：对齐 AlphaGPT 的"1000 步"逻辑（8192×1000≈800 万）；batch 放大 32 倍后，100 万只剩 ~244 步更新，不够模型学习。

- **run 结构** → 6 个 run（3 transformer + 3 matched-random，seed 101/102/103），保留配对比较（备选：减 run 数）— 理由：仍需 Transformer vs 随机的公平对照。

- **执行策略** → 一个 run 一个 run 跑，先跑一个 Transformer，有问题就调，不一次跑完 6 个（备选：一次提交 6 个）— 理由：个人项目，试错驱动，跑了再看显存/吞吐/收敛。

- **scorer** → 10 天持有 / 选 top 20%（2-4 只）/ 相对收益（减同池平均）/ t+1 开盘买入 / 不含交易成本（备选：5 或 20 天、绝对收益、含成本）— 理由：模块化思维，训练用简化稳定目标；10 天折中（短了不符后期 validator 持强势板块的逻辑，长了 A 股轮动快信号不敏感）；相对收益是抽象简洁的选股能力度量；A 股交易成本占比低且前期测试交易频次不高。

- **监工** → 用 watchman skill（备选：自己盯）— 理由：单 run 约 14 小时跨度大，正常静默、异常唤醒。
  - 完成 → 保存产物 + 关机 + 通知用户
  - 崩了/显存爆 → 保存 checkpoint + 关机 + 通知用户决定（调参/resume/换机器）
  - SSH 不可达 → 只能通知用户（连不上无法操作）
  - 逻辑：保存状态和关机是可逆省钱动作，自主做；改参数/resume/换机器改变方案或增加成本，等用户定。

## 待定/未决

- **显存**：batch 8192 在 4090D(24GB) 上可能不够（pilot batch256 用 1.79GB，8192 估 ~50GB）。跑了才知道，爆了降 batch 或换更大显存机器。
- **800 万的真实时长**：pilot 150 attempts/s 估约 14h/run，跑了才能确认；太慢就调 attempts 或换机器。
- **entropy 0.005 是否合适**：盲调值（无 pilot 验证），跑完看 entropy 坍缩程度再定要不要调。

## 事实依据

- **reward-cal pilot（b6f34bf5，配置与 formal 一致 training_invalid_reward=-0.01）**：5 万次平均 reward 仍在涨未收敛，best 在 4352 次见顶，entropy 0.87→0.70 持续降，吞吐 153 attempts/s，显存 1.79GB @ batch256。
  - 来源：`data/processed/v3a/training/runs/v3a-stage-d-reward-calibration-transformer-s314159-b6f34bf5e0f7/training_log.jsonl`、`training_summary.json`
- **reward-cal pilot 与 formal 训练参数逐项一致**：model/optimizer/reinforce/checkpoint 全同，仅 attempts(5万 vs 800万)/seeds(314159 vs 101/102/103)/有无 random 对照/事后处理不同。
  - 来源：`configs/v3a_stage_d_reward_calibration.json` vs `configs/v3a_stage_d_formal_topn.json`
- **AlphaGPT 参考参数**：batch 8192, lr 1e-3, 无 entropy bonus, REINFORCE, 模型 d_model=64/2层/4头/ff128（与我们一致）。
  - 来源：`references/AlphaGPT/model_core/config.py`、`engine.py`、`alphagpt.py`
- **AlphaGen(KDD2023) 论文**：单 alpha RL 优化"在一定步数后基本停止搜索新 alpha"、易陷局部最优；其解法是组合池 reward（我们未采用，属后续研究问题）。
  - 来源：arxiv 2306.12964
