# Validation方案

**时间**：2026-07-18 02:02
**背景**：Stage D Gate 1和训练期复杂度审计已完成，需要在继续封存2022 validation与2023+ final的前提下，冻结一次性validation的候选、最小真实持仓规则和正式判读口径。

**关键决策**：
- Validation职责 → 2022只选择“候选规则/复杂度层级”，不在组内挑具体公式（备选：组内再选top 5）— 理由：避免一年validation被二次筛选；本记录取代早期“2022最多筛5条”的简略约定。
- 候选母池 → 使用每个seed最终200万attempt时的Transformer top50；对100万后新增成员补齐同口径训练期复杂度审计（备选：使用已审计的100万top50或两者并集）— 理由：validation应检验最终冻结训练输出。
- 三套候选规则 → `原始高分组`为最终top50；`稳健复杂组`为其中在S1/S2/S3都优于自身最佳`<=10 token` proper subtree的公式；`对应简化组`为这些短subtree按seed做canonical去重后的集合，复杂-简化配对关系仍保留（备选：独立搜索短公式组或人工写核心公式）— 理由：分别检验训练排行榜、训练期稳健筛选和外围复杂度的样本外价值。
- Random对照 → 从旧formal matched-random ledger截到与各seed最终Transformer相同canonical唯一数，按同一训练期规则和数值门选候选；Random有权否证Transformer，但不是三套复杂度规则之一（备选：只做Transformer内部比较）— 理由：保留AlphaGPT搜索是否优于随机搜索的核心问题。
- 候选数量 → 各组保留规则自然产生的数量，不强制裁成等量；每个seed先做组内统计，三个seed等权（备选：每组每seed固定10条或全部公式直接混算）— 理由：不丢弃合格稳健公式，也不让候选多的seed获得更大投票权。
- 数值门 → 每条候选必须通过CPU/GPU选择一致、full-train reward差`<=1e-6`及两端质量门；不通过则剔除并按训练排名顺延补位（备选：少一条或只信GPU）— 理由：排除已发现的float32 rolling残差伪信号，不使用2022决定补位。
- Validation形态 → 每条公式独立运行一个有限资金、粘性持仓validator；不做多公式集成，不增加统一市场风险开关（备选：继续纯10日scorer或增加市场择时模块）— 理由：比训练scorer接近真实交易，同时尽量隔离公式本身效果。
- 初始建仓 → 初始净值和现金为1；用2021最后一个有效收盘信号，在2022第一个可交易日开盘建仓，不携带训练期持仓或盈亏（备选：2022首日收盘后才生成信号）— 理由：模拟研究完成后的正常部署且不把2021收益带入validation。
- 买入资格 → 当日可选ETF中`rank<=3`且`robust_z>=1.5`，其中`robust_z=(signal-median)/(1.4826*MAD)`；MAD退化时不新买（备选：原始signal>0、外部风险开关或训练期调阈值）— 理由：使用全公式共用、尺度稳健的弱机会门，允许自然空槽但不做人为市场择时。
- 持仓与主动退出 → 最多3只；正式主动退出只有`rank>5`和收盘相对实际买入价亏损`>=7%`；无最长持有期、无止盈、无移动止盈（备选：固定10日、-5%止损或更多风控）— 理由：采用“3进5出”滞回并保留上涨右尾。
- 止损时序 → t日收盘确认`close/entry_open-1<=-7%`，t+1实际开盘卖出；不使用日内最低价假设成交（备选：盘中触发）— 理由：日线下因果清楚，跳空损失按实际开盘承担。
- 止损后重入 → 该ETF必须先至少一天失去买入资格，之后重新满足`rank<=3且robust_z>=1.5`才可买回（备选：立即买回或固定冷却天数）— 理由：防止同一信号下止损后立即回补，又不增加天数参数。
- 次日执行 → t日收盘固定候选，t+1开盘先卖后买；候选无法买入时不向第4名以后补位、不把失败预算追加给其他候选，对应份额留现金（备选：临场扩大候补名单）— 理由：保持前3资格和资金约束不漂移。
- 空槽资金 → 所有当前空槽现金局部池化并按空槽数等分；按排名给合格候选各分配一份，候选不足则余份留现金；已有持仓完全不参与再平衡（备选：独立历史槽资金或全组合再平衡）— 理由：避免新候选仓位由槽位历史随机决定，同时不削减仍被公式看好的赢家右尾。
- 成本与期末 → 正式主口径不计手续费和滑点，现金收益为0；2022末按当日收盘盯市，不读取2023价格虚构平仓（备选：5bp成本主口径）— 理由：当前交易频率预期较低，先隔离公式与持仓规则；严格保持时间边界。
- 主比较分布 → 每seed以组内总收益中位数作生存底线，75%分位作右尾主比较；普通公式明细可完整查看但不参与事后改判（备选：只看中位数、最高值或复合分数）— 理由：保留右尾目标，又不让单条幸运公式决定组胜负。
- 市场基准 → 主基准为2022每日可交易ETF池等权复合净值；年初可交易ETF等权买入持有只作辅助（备选：沪深300或仅Random）— 理由：与多资产ETF机会集和训练相对基准一致。
- 生存门 → 候选规则须在至少2/3 seed满足：组内中位数绝对总收益`>0`、高于主基准、最大回撤中位数不超过20%且不差于主基准（备选：只看绝对或只看相对）— 理由：同时要求赚钱、具有选择增量和风险可接受。
- 复杂规则升级门 → 更复杂或更少筛选的规则要推翻默认简单规则，须75%分位总收益三seed平均领先至少3个百分点、至少赢2/3 seed，并且中位数和最大回撤不差（备选：任何正差、2pp或5pp）— 理由：一年validation的小差异不足以支持增加复杂度。
- 复杂-简化配对门 → 稳健复杂组还须在至少2/3 seed满足`复杂公式总收益-对应简化公式总收益`的配对中位数`>0`（备选：只看组级分布）— 理由：证明外围复杂结构对大多数同源公式有增量，而非少数赢家抬高右尾。
- Random否证门 → 最终Transformer规则相对同canonical Random同样须75%分位平均领先至少3个百分点、至少赢2/3 seed，且中位数和回撤不差；否则不进入2023+ final（备选：Random只报告或“不差”即过）— 理由：没有明确样本外增量就不能宣称学习搜索优于随机。
- 无赢家与默认顺序 → 允许validation没有赢家；所有组失败或Transformer未明确胜Random时停止，不打开final；多组通过但未形成明确优势时，默认`对应简化组 > 稳健复杂组 > 原始高分组`（备选：必须选最高组或多组进final）— 理由：避免在噪声接近时复杂化，也不把final变成第二轮validation。
- Final衔接 → 2022选中规则后，该规则预先冻结的完整公式集原样进入2023+，不按2022挑top 5、不做公式集成；final继续看冻结组级分布（备选：赢家组内再选公式）— 理由：保持2023+未参与任何候选选择。
- 正式与探索分层 → 上述规则决定正式赢家和final路径；2022其他明细可在结果后探索，但不得改变正式赢家。季度分析不预设、不作为固定输出或门槛（备选：事后自由换指标或季度硬门）— 理由：防止看到答案后更换阅卷标准，同时不过度设计个人研究。
