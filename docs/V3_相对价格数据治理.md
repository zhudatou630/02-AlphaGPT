# V3 相对价格数据治理

V3 将研究池扩展为冻结的 35 只 ETF，并把模型终端从绝对 OHLC 改为尺度无关的相对价格。V1/V2 数据、词表和 checkpoint 不得与 V3 混用。

## 数据分工

- TDX 不复权 OHLC 与完整 `gbbq` 事件是价格主源。
- Tushare `fund_daily` 和 `fund_adj` 只用于数据质量对照、零成交识别和 tradable mask。
- 成交量和成交额只存在于本地治理长表，不进入模型 panel 或公式词表。

## 研究特征

每只 ETF 的事件复权价格生成四个终端：

```text
open_rel  = open_t  / adjusted_close_(t-1) - 1
high_rel  = high_t  / adjusted_close_(t-1) - 1
low_rel   = low_t   / adjusted_close_(t-1) - 1
close_rel = close_t / adjusted_close_(t-1) - 1
```

首个交易日、停牌日和零成交日不进入 tradable mask。上市前不填充数据。

## 构建顺序

```bash
cd tools/tdx_exporter
go run . -out ../../data/staging/v3 -start 2005-01-01 \
  -universe ../../configs/research_v3_universe.json

cd ../..
PYTHONPATH=src .venv/bin/python scripts/v3/prepare_raw.py
source .venv/bin/activate
python scripts/v3/download_tushare_probe.py
PYTHONPATH=src python scripts/v3/build_event_adjusted_data.py
```

## 当前结果

- 35 只 ETF，TDX 日线 72,946 行，事件 90 条。
- 应用复权事件 85 条，其中份额扩缩事件 15 条。
- 7 个零成交或折算停牌日保留在治理长表，在研究 panel 中设为不可交易。
- TDX 与 Tushare 复权收益有 4 个超过 1% 的差异，全部位于已审计份额事件日；非事件日超过 1% 的差异为 0。
- 模型 panel shape 为 `35 × 4 × 5196`，只含 `open_rel/high_rel/low_rel/close_rel`。
- 数据日期为 2005-02-23 至 2026-07-10；从 2016-08-09 起可交易 ETF 数量首次达到 10 只。
