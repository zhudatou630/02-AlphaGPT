# V2 价格因子主线

V2 冻结旧 Phase1-3c 研究身份，复用同一套 VM、scorer、validator、Transformer policy 和 REINFORCE 训练框架。V1 token ID 不变，只用于历史审计。

## 数据契约

V2 数据来自 Phase1b event-adjusted 长表，只暴露：

```text
open high low close
```

`volume/amount` 继续用于 Phase1b 数据治理和 tradable mask，但不进入 V2 panel，也不进入公式词表。V2 panel、源 parquet 和 Phase1b summary 均写入 SHA-256；dataset manifest 校验失败时拒绝加载。

```bash
PYTHONPATH=src .venv/bin/python scripts/phase1b_build_event_adjusted_data.py
PYTHONPATH=src .venv/bin/python scripts/v2/build_dataset.py
```

数据产物：

```text
data/processed/v2/dataset/panel_price_event_v2.npz
data/processed/v2/dataset/dataset_manifest.json
```

## 研究契约

V2 checkpoint、JSONL artifact 和 run summary 绑定：

```text
dataset_id / dataset_fingerprint / panel_sha256
feature schema / price adjustment / tradable mask
vocab version / 完整 token names
scorer config
git commit / code fingerprint
```

任一字段不一致时拒绝 artifact reload 或 checkpoint resume。V1 checkpoint schema 会被 V2 明确拒绝。

## 词表

V2 词表版本：

```text
price-event-v2
```

V1 的 `phase3a-v1` 不做原地删改。V2 重新编号，旧整数 token 不得直接迁移。

## 训练

CPU smoke：

```bash
PYTHONPATH=src .venv/bin/python scripts/v2/train_gpu.py \
  --device cpu --batch-size 8 --train-steps 1 --max-len 6 \
  --top-n 2 --cpu-audit-candidates 4 --skip-validator
```

AutoDL CUDA smoke：

```bash
python scripts/v2/train_gpu.py \
  --device cuda --preset 4090d-rms-swiglu-smoke --skip-validator
```

正式运行输出到：

```text
data/processed/v2/training/runs/<run_id>/
```

V2 必须从随机初始化重新训练，不使用旧 checkpoint。

## 当前边界

V2 暂时使用 event-adjusted 绝对 OHLC。绝对价格仍可能带有名义价格尺度和 latest-qfq 的历史缩放问题；后续应单独评估是否改为收益率、价格比值或因果归一化终端。本阶段不把该问题与数据治理迁移混在一起。
