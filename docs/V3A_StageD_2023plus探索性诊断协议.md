# V3A Stage D 2023+ 探索性诊断协议

> 冻结时间：2026-07-18
> 身份：探索性诊断，不是正式final。
> 已知事实：2022正式结果为`no_surviving_rule`，本诊断不得改变该结论。

## 1. 目的

本次永久解封2023+，只观察冻结公式组在不同后续市场环境中的表现，用于判断2022失败是否具有明显
市场状态依赖，以及简单和复杂公式的相对表现是否随年份变化。

无论结果好坏，本次都不产生正式赢家，不把表现好的公式重新标成“通过validation”，也不按2023+
挑公式或修改参数。2023+从本次起永久失去作为下一轮干净final的资格。

## 2. 冻结输入

- 候选继续使用2022运行前冻结的Transformer与Random三组；
- 最终组SHA：`12aa88da48942c11e23f02ec93d83a411e0e61e3cdcdcafaf9dc0a1ffa9f6860`；
- 2022正式机器结果SHA：`3565017f0446861856d8821069283036d1c9e9fbc6d752b65bb92b34bf290409`；
- 交易规则保持`robust_z=1.5`、3进5出、-7%止损、3槽、无交易成本、现金收益0；
- 公式信号仍使用CPU float32。

## 3. 时间与资金路径

- 区间固定为`2023-01-01..2026-07-10`；
- 每条公式从现金1.0开始；
- 使用2022-12-30收盘信号，在2023第一个交易日开盘建仓；
- 整段连续运行，不在2024、2025或2026年初清仓或重置净值；
- 期末按2026-07-10收盘盯市。

逐年收益只从同一条连续净值路径切片：2023以初始净值1.0为分母，此后年度以往年最后一个交易日
净值为分母。不得用每年重新起跑的结果代替连续路径。

## 4. 输出

对每个方法、seed和规则报告：

- 整段总收益、年化收益和最大回撤的组内中位数；
- 整段总收益75%分位数；
- 2023、2024、2025、2026各年收益的组内中位数和75%分位数；
- 同期每日可交易ETF池等权基准；
- 普通公式明细、连续日净值和交易审计。

Random只用于观察搜索方法在后续市场中的分布差异，不形成正式否证门。不得生成正式pass/fail或
winner字段。

## 5. 解释边界

如果2023+表现良好，只能说明公式可能具有明显市场状态依赖，不能推翻2022失败；如果继续失败，说明
当前研究组合在多个后续市场环境中都缺乏支持。任何新训练设计都必须另找新的时间隔离方案，不能再把
2022或2023+当作未使用样本。
