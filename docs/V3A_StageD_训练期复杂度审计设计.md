# V3A Stage D 训练期复杂度审计设计

> 冻结时间：2026-07-16
> 状态：先冻结口径，再实现和运行；不得根据结果调整样本、子期或判读标准。
> 数据边界：只读`2016-08-09`至`2021-12-31`训练期；不读取2022 validation或2023+ final。

## 1. 要回答的问题

Gate 1已经证明后期新公式top10%的全训练期reward提高，但没有证明这些公式跨时间稳定。本审计回答两个更窄的问题：

1. 后期高分公式是否收敛到跨seed相似、在三个训练子期都较稳定的公式区域？
2. 前100万attempt形成的极端top50，是否主要是15-token复杂度带来的单一子期幸运样本？

本审计不重新训练，不改变候选，不读取样本外数据。训练子期都参与过原模型训练，因此即使审计通过，也只能称为“训练期内部稳定”，不能称为样本外有效。

## 2. 三个训练子期

从完整训练split的scorer决策日期按顺序等分为三个连续区间，边界由脚本机械计算并写入结果：

- `S1`：最早三分之一；
- `S2`：中间三分之一；
- `S3`：最后三分之一。

每个子期单独调用原`build_forward_targets`，卖出日不得越过该子期末日。三个子期不得按市场事件手工挑选，也不增加第二套切分。

## 3. 候选集合

只使用Gate 1三个seed的Transformer lane。

### 3.1 早段和末段右尾代表

- 早段：总attempt index `[0, 500000)`；
- 末段：总attempt index `[1500000, 2000000)`；
- 重放archive-tail状态，只保留历史首次出现且语义有效的新canonical；
- 分别取全训练期reward前10%；
- 每个seed、每个阶段按reward排序后等分取200个确定性分位点代表，不随机抽样。

结构特征统计使用前10%全体；子期重评分使用上述代表样本。

### 3.2 前100万复杂候选池

- 范围：总attempt index `<1000000`；
- 同canonical只保留reward最高、token更短、attempt更早的代表；
- 只取`token_len=15`；
- 每个seed按全训练期reward取前500。

其中用原curation规则选出的前50是“极端top50”，其余rank 51-500是复杂度匹配的近邻对照。

### 3.3 短公式对照

从同一seed、同一前100万范围选取：

- `token_len<=5`的全训练期reward前25；
- `6<=token_len<=10`的全训练期reward前25。

每个seed共50条。它们不是样本外对照，只用于判断“复杂度增加后，训练子期最差表现是否同步改善”。

### 3.4 Top50短子表达式

对每条极端top50公式，机械枚举AST中的所有非constant proper subtree，去重后重评分。每条复杂公式的对照锚点固定为“全训练期reward最高的、token_len不超过10的proper subtree”；没有合格subtree则记为不可比较。

这个比较只回答“额外外围结构是否在三个训练子期都增加reward”，不声称subtree与原公式表达相同经济含义。

## 4. 公式区域定义

不事后手工定义`GAP + MEAN(20)`家族。脚本从AST机械提取：

- factor实例集合，例如`GAP`、`ROC_40`、`RSV_5`；
- rolling操作集合，例如`MEAN_20`、`REF_1`；
- 运算符存在性、window token和constant存在性。

“宽家族signature”由factor实例集合和rolling操作集合组成，忽略算术排列、正负号和重复次数。区域收敛用以下描述量：

- early/late top10%各特征出现率；
- late相对early的特征变化，是否在3/3 seed同方向；
- 三seed特征出现率向量的两两cosine相似度；
- 三seed top20宽家族的Jaccard重合；
- 三seed极端top50的exact canonical重合。

## 5. 子期稳定性指标

每条重评分公式记录`full / S1 / S2 / S3` reward，并报告：

- `worst_subperiod_reward = min(S1,S2,S3)`；
- 三子期全部reward为正的比例；
- `subperiod_range = max-min`；
- 三组子期reward两两Spearman相关；
- 极端top50与各子期top50的重合数；
- 极端top50相对短subtree在S1/S2/S3的paired reward差。

全训练期重评分必须先与ledger reward核对。最大绝对误差超过`1e-6`则审计停止，不得继续解释。

### 5.1 执行前一致性门修订

首次执行在产生审计结果前按上述规则停止。根因是少量公式在CUDA上利用多层常数rolling mean的约`1e-8`浮点残差形成非零排序，而CPU得到数学上的精确零；其中一条公式的full reward相差58.90bp。这不是普通float误差，也不是token/reward错位。

为了不把错误CPU信号用于子期评分，一致性门修订为逐公式执行：

- exact token序列的CPU full reward与ledger相差超过`1e-6`，标记`device_sensitive`；
- CPU full signal不满足原coverage/variation质量门，标记`cpu_quality_invalid`；
- 两类公式单独报告并从CPU子期分布、rank和subtree锚点中排除；不得把它们当作零或负reward填回；
- 若任一seed的极端top50出现排除，该seed关于“top50是否幸运复杂样本”的CPU结论作废，必须回到同型号GPU重评分；
- early/late代表样本报告原样本数、排除数和剩余样本结论，设备敏感率本身作为复杂度风险证据。

这是一项由设备数值语义触发的执行口径修订，不改变子期、候选选择或稳定性判读条件。首次失败运行的CPU稳定性输出不得作为研究结果。

## 6. 预先冻结的判读逻辑

### 6.1 “后期学到稳定区域”

只有以下三条同时成立，才判断为“训练期内部支持”；否则判断为“证据混合”或“不支持”：

1. late代表样本的`worst_subperiod_reward`中位数高于early，至少2/3 seed成立；
2. late代表样本的三子期全正比例不低于early，至少2/3 seed成立；
3. late三seed特征向量平均相似度不低于early，并出现至少一个3/3 seed同方向、平均变化不小于5个百分点的结构特征。

该判断只说明模型后期集中到了训练期内部更一致的区域，不说明2022有效。

### 6.2 “极端top50主要是幸运复杂样本”

用四项证据判断，不设单一机械总分：

1. top50中任一子期reward不为正的比例；
2. 前500复杂池的子期rank相关和各子期top50与全期top50重合；
3. top50与短公式对照的`worst_subperiod_reward`；
4. top50相对最佳短subtree是否在三个子期都取得正增量。

解释口径冻结为：

- 若top50绝大多数三期全正、最差子期明显强于短公式，且多数公式对短subtree三期增量都为正，则“不支持主要由幸运样本解释”；
- 若大量top50只靠一个子期、子期排名重排明显、最差子期不优于短公式，或多数复杂外围结构不能在三期同时贡献正增量，则“支持明显的复杂度幸运/选择偏差”；
- 两类证据方向不一致则为“混合”：可承认稳定核心，同时否定极端分数和复杂外围结构的可靠性。

## 7. 明确不能得出的结论

- 不能证明2022或未来有效；
- 不能证明因果Alpha；
- 不能用三个seed替代三个独立市场样本；
- 不能证明15-token是必要复杂度；
- 不能因为训练子期稳定就直接进入策略或扩大到8m attempts；
- 不能试多套子期划分后只报告最有利的一套。
