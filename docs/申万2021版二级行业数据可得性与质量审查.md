# 申万2021版二级行业数据可得性与质量审查

## 1. 结论

Tushare可以提供一张可用于后续机制研究的申万2021版二级行业当前历史面板：

- 当前分类表共有134个L2代码，其中124个标记为发布；
- 这124个当前发布行业从2016-09-09起形成完整横截面；
- 截至2026-07-17共有2,389个交易日、296,236行；
- 主键、交易日、OHLC、成交量和成交额均通过数据门禁；
- 新下载数据与共享raw lake的292,516个重叠行逐值一致；
- 治理副本不需要修复任何价格或收益字段。

因此，数据质量足以支持下一阶段的申万二级行业探索性机制研究。但它仍然是供应商当前发布分类下的历史序列，不是严格的历史点时行业版本。

本轮只检查和固化数据，不计算`ABS(ROC(40))`信号，不运行策略，不接触策略收益。

## 2. 分类身份

接口：

```text
index_classify(level="L2", src="SW2021")
```

返回结果：

| 项目 | 数量 |
|---|---:|
| 分类表代码 | 134 |
| 当前发布代码（is_pub=1） | 124 |
| 当前未发布代码（is_pub=0） | 10 |
| 当前发布代码对应的一级父行业 | 31 |

本面板采用的身份规则是：

```text
CURRENTLY_PUBLISHED_SW2021_L2_ONLY
```

即只下载分类表当前标记为发布的124个二级行业，并完整保存134行分类表以供审计。

10个未发布代码中，9个没有行情；`801011.SI 林业Ⅱ`有2014-02-21至2021-12-10的历史行情，但已停止发布。它不属于当前124行业横截面，因此没有混入本面板。

这个选择建立的是“当前发布的SW2021二级行业回看历史”面板。它适合与此前31个当前SW2021一级行业面板做同类机制研究，但不能解释成当时投资者实际可见且版本不变的点时行业菜单。

## 3. 完整横截面起点

逐个探测134个分类代码在2014-02-21后的行情：

- 121个当前发布代码从2014-02-21开始；
- `801039.SI 非金属材料Ⅱ`从2014-11-07开始；
- `801785.SI 农商行Ⅱ`从2016-09-09开始；
- 9个未发布代码无行情；
- `801011.SI 林业Ⅱ`有历史行情但在2021-12-10终止。

因此，当前124个发布行业共同形成矩形面板的最早日期是：

```text
2016-09-09
```

本轮正式快照从该日开始，不用填充、回补或动态mask伪造更早的完整横截面。

## 5. 质量检查

### 5.1 阻塞门禁

以下项目全部为0：

- 重复`ts_code + trade_date`主键；
- 缺失交易日或每日不足124个行业；
- 非交易日行情；
- OHLC缺失、非有限或非正数；
- `high`低于open/low/close；
- `low`高于open/high/close；
- 成交量或成交额为零或负数；
- 源`change/pct_change`与相邻close计算值的实质差异。

治理结果为：

```text
high修复：0
low修复：0
收益字段修复：0
```

探测更早历史时曾发现`801193.SI`在2015-07-01有一条错误源收益字段，但该日期早于完整面板起点，没有进入正式快照。治理脚本仍按固定容差重新计算并检查所有收益字段，防止未来快照静默引入同类错误。

### 5.2 非阻塞缺失

| 字段 | 缺失行数 | 处理 |
|---|---:|---|
| PE | 273 | 不进入价格信号和交易 |
| 总市值 | 134 | 不进入价格信号和交易 |

OHLC、成交量和成交额没有缺失。后续研究继续只用发布指数点位，不用估值字段。

### 5.3 历史名称变化

31个代码的源`name`在历史中出现过名称变化，主要集中在2021-12-13版本切换，例如：

- 畜禽养殖 -> 养殖业；
- 电子制造 -> 消费电子；
- 船舶制造 -> 航海装备Ⅱ；
- 电源设备 -> 其他电源设备Ⅱ。

Raw和治理数据同时保留：

- `source_name`：Tushare在对应日期返回的历史名称；
- `industry_name`：当前SW2021分类表中的冻结名称。

研究身份使用代码和当前分类名称，历史源名称仅用于审计，不把改名当作新指数，也不据此拼接其他代码。

### 5.4 极端收益检查

相邻收盘计算的最大单日绝对收益为16.55%。超过15%的4行是：

| 日期 | 行业 | 收益 |
|---|---|---:|
| 2024-09-30 | 半导体 | 15.46% |
| 2024-10-08 | 半导体 | 16.55% |
| 2024-10-08 | 电子化学品Ⅱ | 15.57% |
| 2024-10-08 | 电池 | 16.13% |

这些记录的OHLC结构正常，源涨跌幅与相邻close重算一致，并集中在同一轮市场行情中，当前没有数据错误证据，因此不修复。

## 7. 可复现脚本

下载不可变raw快照：

```bash
python scripts/sw_industry/download_sw2021_l2_backcast.py
```

生成治理副本：

```bash
python scripts/sw_industry/build_sw2021_l2_governed.py \
  --source-snapshot data/raw/sw_industry_l2/sw2021_backcast/snapshots/<snapshot-id>
```

脚本根据独立身份配置逐项检查134个分类代码，以及124个当前发布代码的名称、行业代码、父行业映射和发布状态；同时检查2016-09-09后的完整交易日横截面。若Tushare分类身份或历史覆盖发生变化，流程会失败，而不是静默改写研究对象。治理层会再次验证身份配置SHA、分类和日历文件哈希、`SHA256SUMS`、精确代码集、SSE交易日集合及源质量门禁。

## 8. 后续使用边界

这份数据可以进入下一步研究准备，但需要保留以下限制：

1. 它是当前发布124行业的回溯面板，`historical_vintage_proven=false`；
2. 2016-09-09早于SW2021正式生效日，生效日前序列不能声称为当时原生SW2021分类；
3. 当前未发布的历史行业被排除，因此不能称为逐日完整的历史点时二级行业全集；
4. 二级行业指数不可直接交易，后续只能解释为行业机制模拟；
5. 在冻结研究问题和协议前，不应运行或查看策略结果。

在这些边界下，数据的可得性和价格质量均满足后续探索性研究要求。
